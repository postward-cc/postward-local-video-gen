# video-gen-poc

Proof of concept for AI-assisted video generation.

## Scope

Exploration of pipelines and tools for generating short-form videos from text prompts and/or source assets. Targets include text-to-video models, image-to-video, and programmatic composition (e.g. Remotion).

## Status

Early-stage POC. Folder intentionally minimal — content will be added as experiments land.

## Planned experiments

- Text-to-video via hosted models (Wan / Qwen)
- Image-to-video from reference frames
- Programmatic composition / captions over generated clips
